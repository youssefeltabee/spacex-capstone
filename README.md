SpaceX Falcon 9 first-stage landing prediction — capstone project from IBM Data Science Professional Certificate.

## Overview

Predict whether a Falcon 9 first stage will land successfully using public launch data. A successful landing enables rocket reusability, which significantly reduces launch costs (from ~$62M to ~$15M per launch).

## Key Components

- Data collection via SpaceX REST API and web scraping
- Exploratory data analysis with interactive visualizations (Folium)
- Predictive modeling with various classifiers
- Interactive dashboard for launch outcome analysis

## Results

Achieved high accuracy in predicting landing outcomes using features such as payload mass, orbit type, launch site, and flight number.
