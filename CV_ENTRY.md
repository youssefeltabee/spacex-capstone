## Tips for Your CV

1. **Quantify results:** Mention the 92.6% AUC, 90 launches analyzed, 14 slides, etc.
2. **Highlight business impact:** "Identified GTO missions as high-risk" shows business thinking
3. **Show full stack:** Data collection → EDA → Modeling → Visualization → Presentation
4. **Include GitHub link:** Recruiters want to see your code
5. **Tailor for role:**
   - For Data Scientist role: Emphasize ML models, AUC, feature engineering
   - For Data Analyst role: Emphasize SQL, EDA, visualizations, business insights
   - For Data Engineer role: Emphasize data pipelines, SQLite, multiple data sources
